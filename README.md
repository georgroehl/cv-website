# georgroehl.de

Source for [georgroehl.de](https://georgroehl.de), Georg Röhl's professional
portfolio covering embedded software engineering, AI-centered development,
technical leadership, education, and selected projects.

## Local development

```sh
npm start
```

## Production build and deployment

```sh
npm run build
npm run deploy
```

The site is deployed to GitHub Pages and uses the custom domain configured in
`public/CNAME`.
